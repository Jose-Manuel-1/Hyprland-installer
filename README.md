# Hyprland-installer
Este script sirve para instalar hyprland con todo lo necesario para su uso, no hace falta configurar nada, solo clonar el repositorio y ejecutar el archivo install y se te instalará hyprland con sus programas necesarios para usarlo comodamente.
Programas que instala Hyprland-installer: 
- hyprland
- waybar
- foot
- rofi
- grim
- slurp
- wl-clipboard
- cliphist
- mako
- pamixer
- brightnessctl
- thunar
- xdg-desktop-portal-hyprland
- bluem

Creditos de configuraciones:
